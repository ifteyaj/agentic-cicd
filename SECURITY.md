# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities by email to: ifteyajahmed6@gmail.com

Do not open a public GitHub issue for security problems.

Expected response time: within 7 days.

## Scope

This is a capstone research project. The system executes model-generated code in sandboxed
containers. See `docs/security/` for the threat model and containment evidence.
